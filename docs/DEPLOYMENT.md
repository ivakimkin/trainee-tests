# GitHub Pages: прямой вход по паролю

Основной адрес: https://ivakimkin.github.io/trainee-tests/

Tilda больше не требуется. На главной странице перед меню добавлен простой клиентский вход по паролю . Кнопки выхода нет. Доступ хранится только в памяти страницы: обновление страницы снова требует пароль и сбрасывает прохождение. В «Секретарь · Вариант 1» кнопка «Пройти заново» также возвращает к паролю.

Это согласованное простое ограничение от случайных посетителей. Файлы и исходный код публичны. Результаты тестов отображаются локально и не отправляются на сервер.

Сборка: `python3 tools/build_pages.py`. Параметры проверки пароля находятся в tools/password-gate.json; открытый пароль в репозиторий не сохраняется. Генератор использует сохранённые salt и digest, поэтому при пересборке пароль не меняется.

Настройки Pages: Deploy from a branch → main → /docs. После push дождаться успешного pages build and deployment во вкладке Actions.

Проверка входа: `node tools/check_password_gate.cjs` в подготовленной облачной среде. Проверка читает пароль из /workspace/trainee-tests-password.txt вне репозитория. Она проверяет неверный и верный пароль, повторный запрос пароля при обновлении, запуск теста и выход на двух размерах экрана. Запросы к GitHub Pages в ней заменяются локальным файлом; опубликованный домен проверяется отдельно.
